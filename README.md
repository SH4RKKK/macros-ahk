# macros-ahk

A set of AutoHotkey scripts that hold down keys, forward inputs between windows,
and automate repetitive interactions based on pixel detection.

**Language:** AutoHotkey v1

## Scripts

- **Gunslinger.ahk**, holds configured keys and fires them on a loop at a set interval *(March 2021)*
- **MultiBox_Control.ahk**, forwards keystrokes from one window to other running instances *(November 2020)*
- **XP_Farm.ahk**, detects UI states via pixel search and cycles through interactions automatically *(October 2020)*
